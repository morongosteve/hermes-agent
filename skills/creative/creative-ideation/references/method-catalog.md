# Method Catalog

One-line summary + when-to-use for every method in `references/methods/`. Use this to confirm a route or to pick when two seem plausible. Load only the method file you will actually apply.

| Method | One line | Reach for it when |
|---|---|---|
| **lateral-provocations** | Deliberately false/absurd statements (PO) used as stepping stones. | "Make it weird", high-slop terrain, obvious answer is boring. |
| **pataphysics** | The science of imaginary solutions; take the exception as the law. | You want genuine strangeness with internal logic, not just randomness. |
| **scamper** | Substitute/Combine/Adapt/Modify/Put-to-other-use/Eliminate/Reverse on an existing thing. | EXPANDING — you have a base idea and want variations. |
| **premortem-and-inversion** | Assume it failed; work backwards to why. Invert the goal. | SELECTING, de-risking, finding the non-obvious failure. |
| **compression-progress** | Pick the idea that most compresses your model of the world (max learnable surprise). | Picking a research question or the highest-upside option. |
| **oblique-strategies** | A single aphoristic constraint card forces a lateral move. | UNBLOCKED needed; stuck mid-project; music/art/object work. |
| **defamiliarization** | Make the familiar strange; describe as if seen for the first time. | REFINING text — prose feels flat, clichéd, invisible. |
| **creative-discipline** | Tharp's "spine" + box: habit, a single organizing idea, ruthless cutting. | REFINING non-text; a sprawling project needs a spine. |
| **affinity-diagrams** | Cluster raw observations bottom-up until themes emerge. | SYNTHESIZING a pile of notes/interviews/data. |
| **volume-generation** | Quantity first; quota of N, defer judgment, mine the tail. | You need many options fast and the first few are predictable. |
| **oulipo** | Formal constraints (lipogram, N+7, snowball) generate text. | TEXT — poetry/formal; constraint as engine. |
| **story-skeletons** | Reusable narrative spines (quest, voyage-and-return, rags-to-riches…). | TEXT — narrative; you need a shape to hang material on. |
| **chance-and-remix** | Cut-up, decks, dice, found material recombined. | TEXT/OBJECT — you have source material to remix. |
| **triz-principles** | 40 inventive principles resolve a technical contradiction. | ARTIFACT — two engineering parameters conflict. |
| **pattern-languages** | Alexander-style named patterns compose into a whole. | ARTIFACT — software architecture / recurring structure. |
| **biomimicry** | Ask how nature already solved the function. | ARTIFACT — there's a natural-system analog. |
| **first-principles** | Strip to physical/logical bedrock; rebuild without inherited assumptions. | ARTIFACT — accumulated "that's how it's done" to question. |
| **leverage-points** | Meadows' places to intervene in a system, ranked by power. | SYSTEM — civic/org/institutional change. |
| **derive-and-mapping** | Debord's drift; wander the space, map subjective terrain. | SELF — life/career/what-to-study; unknown territory. |
| **polya** | Understand → plan → execute → look back; heuristics for solving. | RESEARCH/ARTIFACT — a known problem to crack. |
| **jobs-to-be-done** | What job is the customer "hiring" this for? Progress in a context. | PRODUCT — business/service framing. |
| **analogy-and-blending** | Map structure from a source domain; blend two inputs into a third. | Any domain — break a frame, find a generative analogy. |

See `SKILL.md` "Routing" for the full decision procedure. See `references/anti-slop.md` for the quality bar every method's output must clear.
